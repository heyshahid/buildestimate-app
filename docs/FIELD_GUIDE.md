# On-Site Field Takeoff Guide

This guide is designed for General Contractors, Project Superintendents, and remote Construction Virtual Assistants (VAs).

---

##  1. Preparing for On-Site Measurement
1. **Always establish zero reference datum:** Measure inside face to inside face for wall linings, or outside-to-outside for foundation slab footprints.
2. **Account for Subgrade Irregularities:** Uncompacted gravel sub-base or uneven earth work typically requires bumping concrete waste from 10% to 15%.
3. **Window & Door Deductions:** Standard residential doors (3'x6'8") deduct ~20 sq ft. Double sliding patio doors (6'x6'8") deduct ~40 sq ft. Standard windows (3'x4') deduct 12 sq ft.

---

##  2. Using the Progressive Web App (Offline Mode)
- **Safari (iOS):** Tap the Share icon $\rightarrow$ *Add to Home Screen*.
- **Chrome (Android / Desktop):** Tap the Install button in the address bar.
- **Data Persistence:** Estimates are cached automatically in `localStorage`. They remain accessible mid-flight, in subterranean basements, or in rural construction zones without 4G/5G reception.

---

##  3. 1-Page PDF Proposal Workflow
1. Complete Concrete, Framing, Drywall, or Paint modules.
2. Navigate to **Master Bid Proposal**.
3. Fill in Client Name, Project Address, Labor Hours, Subcontractors, and Equipment rentals.
4. Set Contractor Profit Margin (typically 15% to 25%).
5. Tap **Print / Export 1-Page Proposal**. The stylesheet automatically suppresses navigation, sets high-contrast print typography, and generates a formal client signature line on a single letter-size page.
